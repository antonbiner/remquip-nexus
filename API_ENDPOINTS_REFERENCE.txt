AUTHENTICATION ENDPOINTS (8)
============================

1. POST /api/auth/register
   Request: { first_name, last_name, email, password, company_name?, phone? }
   Response: { user_id, email, token?, created_at }
   Error: 400 (invalid), 409 (email exists), 500 (server)

2. POST /api/auth/login
   Request: { email, password }
   Response: { user_id, token, refresh_token, expires_at }
   Error: 401 (invalid), 404 (user not found)

3. POST /api/auth/logout
   Request: { token }
   Response: { success: true }

4. POST /api/auth/refresh-token
   Request: { refresh_token }
   Response: { token, refresh_token, expires_at }
   Error: 401 (expired/invalid)

5. POST /api/auth/forgot-password
   Request: { email }
   Response: { message: "Reset link sent", token_id }
   Error: 404 (user not found)

6. POST /api/auth/reset-password
   Request: { token, new_password }
   Response: { success: true }
   Error: 400 (invalid token), 401 (expired)

7. POST /api/auth/verify-email
   Request: { token }
   Response: { success: true, email_verified }
   Error: 400 (invalid), 401 (expired)

8. POST /api/auth/resend-verification
   Request: { email }
   Response: { message: "Verification sent" }
   Error: 404 (user not found), 429 (rate limit)


CUSTOMER PROFILE ENDPOINTS (10)
===============================

1. GET /api/customers/me
   Auth: Required (Bearer token)
   Response: {
     id, email, first_name, last_name, company_name, 
     phone, avatar_url, status, email_verified, created_at, 
     updated_at, last_login
   }
   Error: 401 (unauthorized), 404 (user not found)

2. PATCH /api/customers/me
   Auth: Required
   Request: { first_name?, last_name?, company_name?, phone? }
   Response: { success: true, customer: {...} }
   Error: 400 (validation), 401 (unauthorized)

3. PUT /api/customers/me/avatar
   Auth: Required
   Request: { file: FormData (image) }
   Response: { avatar_url, updated_at }
   Error: 400 (invalid file), 413 (too large)

4. PATCH /api/customers/me/password
   Auth: Required
   Request: { current_password, new_password }
   Response: { success: true }
   Error: 401 (wrong password), 400 (validation)

5. DELETE /api/customers/me
   Auth: Required
   Request: { password } (confirmation)
   Response: { success: true }
   Error: 401 (wrong password)

6. GET /api/customers/preferences
   Auth: Required
   Response: {
     newsletter_subscribed, order_updates, promotional_emails,
     sms_notifications, preferred_language, preferred_currency,
     two_factor_enabled
   }

7. PATCH /api/customers/preferences
   Auth: Required
   Request: { newsletter_subscribed?, order_updates?, promotional_emails?, ... }
   Response: { success: true, preferences: {...} }

8. GET /api/customers/me/settings
   Auth: Required
   Response: { account_type, account_age, total_orders, total_spent }

9. POST /api/customers/me/two-factor-setup
   Auth: Required
   Response: { qr_code_url, secret_key }

10. POST /api/customers/me/two-factor-verify
    Auth: Required
    Request: { code }
    Response: { success: true, backup_codes: [] }

CUSTOMER ORDERS ENDPOINTS (6)
=============================

1. GET /api/customers/orders
   Auth: Required
   Query: { limit: 10, offset: 0, status?, sort_by? }
   Response: {
     orders: [
       { id, order_number, status, total_amount, created_at, 
         items_count, tracking_number, carrier, estimated_delivery }
     ],
     total_count, page, pages
   }

2. GET /api/customers/orders/:orderId
   Auth: Required
   Response: {
     id, order_number, status, total_amount, tax_amount, shipping_cost,
     subtotal, created_at, updated_at, tracking_number, carrier,
     estimated_delivery, items: [...], billing_address, shipping_address,
     payment_method, notes
   }
   Error: 404 (not found), 403 (forbidden)

3. GET /api/customers/orders/:orderId/tracking
   Auth: Required
   Response: {
     order_number, status, tracking_number, carrier,
     estimated_delivery, last_update, events: [
       { status, timestamp, location, message }
     ]
   }

4. GET /api/customers/orders/:orderId/timeline
   Auth: Required
   Response: {
     events: [
       { status, date, message, location }
     ]
   }

5. GET /api/customers/orders/:orderId/invoice
   Auth: Required
   Response: { pdf_url } or PDF binary (download)
   Error: 404 (not found), 403 (forbidden)

6. POST /api/customers/orders/:orderId/cancel
   Auth: Required
   Request: { reason? }
   Response: { success: true, status: "cancelled" }
   Error: 400 (cannot cancel), 404 (not found)
